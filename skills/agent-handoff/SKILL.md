# agent-handoff

## 只做这一件事

在**转出方 A 零准备**的前提下，用 1 条外部命令拉齐现场、核对 6 项可验收状态并直接接管。**返场方（A→B→A）严禁沿用旧对话记忆，必须重跑本流程。**

**不做**：同会话断流/暂停后说「继续」的常规续写、日常写前留痕（`task-checkpoint`）、双人并发协作（`agent-collab`）、大知识库整理（`kb-retrieval`）。

## 接手三步（单命令优先）

1. **运行 1 条汇总命令**（禁止手动拼一串 git/目录查询）：
   ```bash
   skein-cli resume
   ```
   它会自动输出：后台写入冲突检测、**仅当前子项目**的最小档案、Git 实时现场、活跃任务锚点、以及 `ai-memory`（或备选日志工具）外部留痕摘要。

2. **执行两项硬闸门判定**：
   - **现场占用判定（区分“窗口开着已停写”与“后台命令正在写”）**：
     - 若有 `[WARN_BG_ACTIVE]`、已知仍在写的后台命令或未解释的产物变化，先核查进程与产物。仅在确认持续写入或锁归属仍有疑问时暂停写入，必要时询问用户是否等待或终止。单次保存无需确认。（这是单任务中断冲突，不属于双 Agent 实时协作。）
     - 若仅是 A 的窗口开着但无后台写入 → **直接接手**，不要求用户关闭 A。
   - **任务定位判定**：
     - `TASK_ANCHOR: SINGLE`（唯一未完任务）→ **直接恢复**，不要多问一句。
     - `TASK_ANCHOR: MULTIPLE`（多个未完任务）→ **列出清单请用户选择**，禁止猜测。
     - `TASK_ANCHOR: NONE`（A 未留锚点即中断）→ 结合当前子项目最小档案 + Git 现场 + `ai-memory` 摘要（必要时仅重查中断前一小段未成结论的探索）重建现状。

若简报提示约束、决定、排除项或假设被省略，且可能影响下一步，按任务运行 `skein-cli resume --id <ID> --full`。

3. **按 6 项可验收清单简要复述并开工**：
   接手开干前，用不超过 6 行确认已找回：
   1. 用户最后确认的目标
   2. 变更过的约束
   3. 关键决定及理由
   4. 已排除的方案（严禁重复试错）
   5. 当前待验证假设
   6. 可直接执行的下一步

## 保护底线

- 严禁读取其他无关子项目的档案，严禁为了“熟悉项目”通读源码。
- 发现未记录的脏文件时**绝不执行 `git clean` 或丢弃改动**，先查来源或询问用户。
- 遇到异常冲突（档案与现场矛盾、工作树损坏等）查 `references/recovery.md`；仍无法解释则停手报 `[HANDOFF_GAP]`。
