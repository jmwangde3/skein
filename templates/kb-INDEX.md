# {{PROJECT}} · 知识库索引

> 本文件是入口，**只读这一份不足以开工**，它是导航不是内容。
> 目标：读完这一页，知道下一步该打开哪个文件。
> 篇幅控制在 1000 tokens 以内。超了说明你把内容写进了目录。

## 这个库管什么

存 {{PROJECT}} 的事实、决策、操作手册和流水。
**不管**任务状态——那是任务库的事，看 `bd -C <store> list`。
**不管**当前进度——看 `current.md`。

## 分类

| 目录 | 放什么 | 什么时候看 |
|---|---|---|
| `current.md` | 现在到哪一步、下一步 | 每次开工第一件事 |
| `facts/` | 环境、版本、接口约定等稳定事实 | 要确认"到底是不是这样" |
| `decisions/` | 定过的事 + 为什么 + 否掉了什么 | 想推翻旧做法之前 |
| `runbooks/` | 可照抄的操作步骤 | 要重复做同一件事之前 |
| `journal/` | 按月流水，只追加不改 | 回顾"上个月在忙什么" |
| `proposals/` | 非写者的改动建议 | 你不是当前写者时 |
| `archive/` | 归档的旧文档 | 只按需查，不进常规检索 |

## 常查

| 我想知道 | 看哪里 |
|---|---|
| 现在做到哪了 | `current.md` |
| 这个决定为什么这么定 | `decisions/` 里按主题找 |
| 上次这个错怎么修的 | `runbooks/` |
| 环境里装了什么版本 | `facts/` |

## 写入规则

同一时刻只有一个写者直接改本库。其他人写 `proposals/<日期>-<主题>.md`，由写者合并。
每次写完立刻 commit。
